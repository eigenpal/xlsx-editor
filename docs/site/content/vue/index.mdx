`@xlsx-editor.dev/vue` is the Vue 3 twin of `@xlsx-editor.dev/react`. Its parts have the same props, markup, and behavior as the React parts. A parity check in the repository keeps the two adapters in step.

## Install and mount

Install the adapter, its engine peer, and Vue:

```bash
npm install @xlsx-editor.dev/vue @xlsx-editor.dev/core vue
```

Import the stylesheet once and give `XlsxEditor` a height:

```vue
<script setup lang="ts">
import { XlsxEditor } from '@xlsx-editor.dev/vue';
import '@xlsx-editor.dev/vue/styles.css';

defineProps<{ bytes: Uint8Array }>();
</script>

<template>
  <XlsxEditor :document="bytes" style="height: 600px" />
</template>
```

For a complete page that opens a file and saves the edits, see the [Quickstart](/docs/quickstart).

## Map the React API to Vue

The React guides describe the parts in detail, and the Vue parts behave the same. Read them with these differences:

| React | Vue |
| --- | --- |
| A callback prop, such as `onSave` or `onChange` | An event without the `on` prefix, such as `@save` or `@change` |
| `XlsxEditor.Root`, `XlsxEditor.Viewport`, `XlsxEditor.Content` | `XlsxEditorRoot`, `XlsxEditorViewport`, `XlsxEditorContent`. Each part is also a static of `XlsxEditor`, as in React |
| `XlsxEditor.Toolbar.Slot` with `slotId` | `XlsxEditorToolbar.Slot` with `slot-id` |
| A hook, such as `useEditorCommand` | A composable of the same name. It returns refs for the state, and plain functions such as `execute` and `t` |
| `useRef<XlsxEditorRef>` | `useTemplateRef<XlsxEditorRef>` |
| `className` | `class` |

## Choose an API

| Task | API | Guide |
| --- | --- | --- |
| Configure the packaged editor | `XlsxEditor` props and events | [Props and events](https://github.com/eigenpal/xlsx-editor/blob/main/packages/vue/README.md#props-and-events) |
| Arrange or replace the chrome | `XlsxEditorRoot`, `XlsxEditorViewport`, `XlsxEditorContent`, `XlsxEditorToolbar`, and the other parts | [Build your own layout](https://github.com/eigenpal/xlsx-editor/blob/main/packages/vue/README.md#build-your-own-layout) |
| Change the toolbar and read each key | `XlsxEditorToolbar` props, `XlsxEditorToolbar.Slot`, and `XlsxEditorToolbar.Group` | [Toolbar and keyboard](https://github.com/eigenpal/xlsx-editor/blob/main/packages/react/docs/toolbar-and-keyboard.md) |
| Edit cells from code, and save | `XlsxEditorRef`, `getEditor()`, and `save()` | [Edit cells](https://github.com/eigenpal/xlsx-editor/blob/main/packages/react/docs/editing-cells.md) |
| Format cells, and insert or delete rows and columns | The editor instance and `useEditorCommand` | [Format cells and change the structure](https://github.com/eigenpal/xlsx-editor/blob/main/packages/react/docs/formatting-and-structure.md) |
| Add, rename, and move sheets, copy and paste, and set sizes | The editor instance | [Sheets, clipboard, and sizes](https://github.com/eigenpal/xlsx-editor/blob/main/packages/react/docs/sheets-clipboard-and-sizes.md) |
| Show a workbook that the user cannot change | `mode="view"` | [View mode and protection](https://github.com/eigenpal/xlsx-editor/blob/main/packages/react/docs/view-mode-and-protection.md) |

| Translate the interface | `locale` and `useTranslation` | [Language](/docs/customization/language) |

## Limits

- The adapter requires Vue 3.5 or later and one shared copy of `@xlsx-editor.dev/core`.
- Composables read the editor only in a descendant of `XlsxEditorRoot`.
- `XlsxEditor` renders its own toolbar and takes no toolbar parts. To pass parts, build your own layout with `XlsxEditorToolbar`.
- The editor runs in the browser. If your app renders on a server, render the editor only in the browser, for example in the `<ClientOnly>` component of Nuxt.
