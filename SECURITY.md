# Security policy

## Supported versions

| Version | Supported                   |
| ------- | --------------------------- |
| 0.x     | Yes, from the first release |

No version is published yet. This policy applies from the first release.

## Report a vulnerability

Use a [GitHub Security Advisory](https://github.com/eigenpal/xlsx-editor/security/advisories/new) to report a vulnerability. Do not open a public issue.

We aim to acknowledge reports within five business days. We will provide updates about the fix and disclosure timeline.
