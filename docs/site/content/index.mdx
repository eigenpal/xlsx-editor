XLSX Editor is a WYSIWYG editor for `.xlsx` workbooks in React and Vue 3. It reads the package in the browser and lays out the grid by the rules of ECMA-376. It paints the grid on a canvas, and saves the edited workbook as bytes. Editing needs no upload or conversion service.

A cell shows the value that the file stores. The editor does not calculate formulas. After an edit that can change a result in a workbook with formulas, it marks the stored results as possibly out of date. The saved workbook then sets `x:calcPr/@fullCalcOnLoad`, which asks the next consumer to calculate them again. [XLSX fidelity](/docs/xlsx-fidelity#round-trip-contract) names one known exception.

## Install an editor

Install an adapter, the engine, and the framework:

<FrameworkTabs>
<Framework value="react">

```bash
npm install @xlsx-editor.dev/react @xlsx-editor.dev/core react react-dom
```

</Framework>
<Framework value="vue">

```bash
npm install @xlsx-editor.dev/vue @xlsx-editor.dev/core vue
```

</Framework>
</FrameworkTabs>

Import the stylesheet once, and give the editor a height:

<FrameworkTabs>
<Framework value="react">

```tsx
import { XlsxEditor } from '@xlsx-editor.dev/react';
import '@xlsx-editor.dev/react/styles.css';

export function Workbook({ bytes }: { bytes: Uint8Array }) {
  return <XlsxEditor document={bytes} style={{ height: 600 }} />;
}
```

</Framework>
<Framework value="vue">

```vue
<script setup lang="ts">
import { XlsxEditor } from '@xlsx-editor.dev/vue';
import '@xlsx-editor.dev/vue/styles.css';

defineProps<{ bytes: Uint8Array }>();
</script>

<template>
  <XlsxEditor :document="bytes" style="height: 600px" />
</template>
```

</Framework>
</FrameworkTabs>

To open a file and save the edits, continue with the [quickstart](/docs/quickstart).
