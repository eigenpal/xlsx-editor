The editor chrome changes through props, parts, and hooks. The grid always shows the workbook as the file defines it: its colors, fonts, and sizes. Start with the smallest change that works.

## Choose a customization API

Each guide holds the samples and the rules of its API. The Vue parts take the same props, as [@xlsx-editor.dev/vue](/docs/vue#map-the-react-api-to-vue) describes.

| Guide | Use it to | API |
| --- | --- | --- |
| [Build your own layout](https://github.com/eigenpal/xlsx-editor/blob/main/packages/react/README.md#build-your-own-layout) | Arrange the chrome parts around the grid | `XlsxEditor.Root`, `.Viewport`, `.Content`, and the chrome parts |
| [Layout and props](https://github.com/eigenpal/xlsx-editor/blob/main/packages/react/docs/layout-and-props.md) | Read the props of each part, and keep the status message in your layout | `XlsxEditor.Viewport`, `XlsxEditor.StatusMessage` |
| [Toolbar parts](https://github.com/eigenpal/xlsx-editor/blob/main/packages/react/docs/toolbar-and-keyboard.md#toolbar-parts) | Hide, replace, or add toolbar controls | `hidden`, `preset`, `XlsxEditor.Toolbar.Slot`, `XlsxEditor.Toolbar.Group` |
| [Controls of your own](https://github.com/eigenpal/xlsx-editor/blob/main/packages/react/docs/toolbar-and-keyboard.md#controls-of-your-own) | Bind your own control to a toolbar command | `useEditorCommand(slotId)` |
| [Appearance](/docs/customization/appearance) | Set the color tokens, the corner radius, and the font of the chrome, and theme your own popups | `--doc-*` tokens, `className`, `useScopeClassName()` |
| [Color mode](https://github.com/eigenpal/xlsx-editor/blob/main/packages/react/docs/layout-and-props.md#color-mode) | Set the light, dark, or system theme of the chrome | `colorMode`, `useEditorColorMode()` |
| [High contrast themes](https://github.com/eigenpal/xlsx-editor/blob/main/packages/react/docs/layout-and-props.md#high-contrast-themes) | Check each chrome state in a forced colors theme | No prop |
| [Number locale](https://github.com/eigenpal/xlsx-editor/blob/main/packages/react/docs/layout-and-props.md#number-locale) | Set the separators, the built-in format codes, and the currency symbol | `numberLocale` |
| [Font changes](https://github.com/eigenpal/xlsx-editor/blob/main/packages/react/docs/layout-and-props.md#font-changes) | Replace the faces that measure and paint text | `fonts`, `onFontError` |
| [Serve the text shaper](https://github.com/eigenpal/xlsx-editor/blob/main/packages/core/README.md#serve-the-text-shaper) | Serve the faces and the shaper from your own address | `setHarfBuzzWasmUrl`, `FontSource` |
| [Editor events](/docs/customization/events) | Run your own code on a content change, a selection change, a refused edit, or a failed open | `useEditorEvent(event, handler)`, `editor.on(event, handler)` |
| [Language](/docs/customization/language) | Translate the interface | `locale`, `useTranslation()` |
| [Hooks](/docs/react/hooks), [Vue composables](/docs/vue/composables) | Read the editor state in your own parts | `useEditorState`, `useEditorColorMode`, and the other hooks |
